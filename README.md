# goats-studio

Продающий сайт студии: услуги, цены, кейсы, процесс, ответы на возражения, контакты.
Next.js 16 (App Router) + TypeScript, три языка, статическая генерация.

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000 → редирект на /ru
npm run build    # прод-сборка, все языки в статику
npm run typecheck
```

Деплой на Vercel — из коробки, настраивать нечего.

## Структура

```
app/[locale]/layout.tsx   <html lang>, метатеги, hreflang, шрифты
app/[locale]/page.tsx     порядок секций страницы
app/globals.css           вся вёрстка, палитра в :root
app/sitemap.ts            sitemap.xml с языковыми альтернативами
app/robots.ts             robots.txt
proxy.ts                  / → /ru
components/               по компоненту на секцию
i18n/locales/             ru.ts · kk.ts · en.ts — все тексты
content/site.ts           ссылки, контакты, кейсы, цены, стек
public/cases/             скриншоты проектов
```

## Модель страницы

Порядок блоков собран под продажу, а не под рассказ о себе:

1. **Оффер** — что получит клиент, а не какой у нас стек.
2. **Боль** — четыре ситуации, в которых клиент себя узнаёт.
3. **Услуги** — то же самое, но уже как решения.
4. **Цены** — три пакета с суммой и сроком. Отсекает нецелевых.
5. **Кейсы** — задача → результат, с цифрой.
6. **Процесс** — четыре шага и что клиент получает на каждом.
7. **Почему мы** — снимает возражения про цену, права на сайт и поддержку.
8. **Стек** → **FAQ** → **Контакты**.

На телефоне снизу закреплена кнопка Telegram — связаться можно с любого экрана.

## Что нужно заполнить перед показом клиенту

- **Цены** — `content/site.ts`, массив `packages`. Сейчас там заглушки.
- **Скриншоты кейсов** — положить в `public/cases/`, см. README рядом.
  Пока файла нет, показывается CSS-макет, ничего не ломается.
- **Домен** — `site.url` в `content/site.ts`, от него считаются canonical, OG и sitemap.

## Как править

- **Тексты** — только в `i18n/locales/`. Русский файл задаёт структуру:
  добавили ключ в `ru.ts` — TypeScript потребует его в `kk.ts` и `en.ts`.
- **Цвета** — `--accent` и `--accent-soft` в начале `app/globals.css`, рядом лежат альтернативы.
- **Кейсы** — ссылки и стек в `content/site.ts`, тексты в словарях по тому же `id`.
- **Языки** — добавляются в `i18n/config.ts` плюс новый файл в `i18n/locales/`.
