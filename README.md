# goats-studio

Сайт команды разработки: услуги, кейсы, процесс работы, контакты.

Статика без сборщика — HTML, CSS и немного JS. Открывается двойным кликом по `index.html`,
деплоится как есть на GitHub Pages, Vercel или любой хостинг.

```
index.html        разметка страницы
css/style.css     стили, палитра в :root
js/main.js        меню, прогресс скролла, появление блоков, счётчик цифр
assets/           превью проектов (см. assets/README.md)
```

## Как править

- **Цвета** — переменные `--accent` и `--accent-soft` в начале `css/style.css`,
  рядом лежат готовые альтернативы.
- **Кейсы** — блоки `<a class="case">` в `index.html`: задача, результат, стек и ссылка.
  Строки с пометкой `<!-- цифра-заглушка -->` нужно заменить реальными данными.
- **Превью кейсов** — положить картинки в `assets/`, они подставятся вместо CSS-макетов.
