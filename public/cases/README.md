# Скриншоты кейсов

Положите сюда файлы — они автоматически подставятся в карточки вместо CSS-макетов.
Пока файла нет, показывается макет, ничего не ломается.

| Файл                | Проект                 | Формат                     |
|---------------------|------------------------|----------------------------|
| `triathlon.png`     | Aktau Triathlon Fest   | горизонтальный, ~1600×1000 |
| `carte.png`         | CARTE — QR меню        | вертикальный, ~1170×2000   |
| `nutrient.png`      | Nutrient               | горизонтальный, ~1600×1000 |
| `aquagym.png`       | AquaGym                | горизонтальный, ~1600×1000 |
| `gep.png`           | Global Export Partners | горизонтальный, ~1600×1000 |
| `smartziyatker.png` | Smart Ziyatker         | горизонтальный, ~1600×1000 |

Скриншот обрезается по верхнему краю (`object-position: top center`),
так что первый экран сайта виден целиком.

Имена файлов заданы в `content/site.ts` — если переименуете, поправьте там же.
