# Скриншоты кейсов

Имена файлов заданы в `content/site.ts`. Пока файла нет, в карточке
показывается CSS-макет — ничего не ломается.

| Файл                | Проект                 | Состояние |
|---------------------|------------------------|-----------|
| `triathlon.jpg`     | Aktau Triathlon Fest   | снят с сайта |
| `carte.jpg`         | CARTE — QR меню        | промо-кадр из App Store |
| `aquagym.jpg`       | AquaGym                | снят с сайта |
| `gep.jpg`           | Global Export Partners | снят с сайта |
| `smartziyatker.jpg` | Smart Ziyatker         | снят с сайта |
| `nutrient.jpg`      | Nutrient               | **нужен**, см. ниже |

Скриншот обрезается по верхнему краю (`object-position: top center`),
так что первый экран сайта виден целиком.

## Как снимать

Горизонтальные — первый экран сайта, 1600×1000, JPEG. PNG для фотографий
даёт под мегабайт на файл, JPEG качества 82 — около 150 КБ при той же картинке.

## Nutrient

Скриншота нет намеренно. На `nutrient.10k.kz`:

- истёк SSL-сертификат (`NET::ERR_CERT_DATE_INVALID`) — браузер показывает
  предупреждение вместо сайта;
- страница брендирована «Joozlet Marketplace», а не Nutrient;
- корень редиректит на `/login`, публичной части нет.

Нужен либо рабочий адрес, либо скриншот кабинета изнутри. Пока в карточке
CSS-макет дашборда — он выглядит уместнее экрана входа.

## CARTE

В карточке телефонная рамка нарисована прямо в промо-кадре из App Store,
поэтому у кейса стоит флаг `promo: true` — свой мокап не добавляется.
Если появится «сырой» скриншот приложения без рамки, флаг надо убрать.
