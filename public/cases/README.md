## Как снимать

Вьюпорт 1280×1000 CSS при `deviceScaleFactor: 1.25` — на выходе 1600×1250.
Пропорция 1.28 близка к контейнеру крупной карточки: при 1600×1000 (1.6)
`object-fit: cover` срезал сайту бока вместе с логотипом.

JPEG качества 82. PNG для скриншотов с фотографиями даёт под мегабайт на файл.

Кадр обрезается по верхнему краю (`object-position: top center`),
так что первый экран виден целиком.

## CARTE

Телефонная рамка нарисована прямо в промо-кадре из App Store, поэтому у кейса
стоит флаг `promo: true` — свой мокап не добавляется, иначе телефон в телефоне.
Если появится «сырой» скриншот приложения без рамки, флаг надо убрать.
